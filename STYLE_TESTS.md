# STYLE_TESTS.md
Machines That Talk Too Much

This file defines **allowed vs forbidden writing patterns**.
Use it as a test suite for tone and language.

---

## Test 1: Anthropomorphism

❌ Forbidden:
> “The model understands grammar.”

✅ Allowed:
> “The model produces outputs that match grammatical patterns.”

---

## Test 2: Hype Language

❌ Forbidden:
> “This breakthrough changed everything.”

✅ Allowed:
> “This change removed a constraint that previously limited scale.”

---

## Test 3: Intelligence Claims

❌ Forbidden:
> “The system reasons about the problem.”

✅ Allowed:
> “The system predicts likely continuations based on prior text.”

---

## Test 4: Motivational Tone

❌ Forbidden:
> “This is an exciting time for AI.”

✅ Allowed:
> “Model capabilities increased as data and compute increased.”

---

## Test 5: Jargon Inflation

❌ Forbidden:
> “The architecture leverages sophisticated representational learning.”

✅ Allowed:
> “The model adjusts parameters to reduce prediction error.”

---

## Test 6: Over-Explanation of Prior Parts

❌ Forbidden:
> “As explained earlier, language models work by predicting the next word…”

✅ Allowed:
> “Language models predict the next word.”

---

## Test 7: Forward References

❌ Forbidden:
> “Later models would solve this problem.”

✅ Allowed:
> “At the time, this problem remained unsolved.”

---

## Test 8: Human Analogies

❌ Forbidden:
> “The model learns language like a child.”

✅ Allowed:
> “The model is trained on large amounts of text.”

---

## Test 9: Blog Style

❌ Forbidden:
> “So what does this mean for us?”

✅ Allowed:
> “The result was a change in how models were evaluated.”

---

## Test 10: Scope Discipline

❌ Forbidden:
> “This raises deep questions about consciousness.”

✅ Allowed:
> “These questions are outside the scope of this book.”

---

## Final Rule

If a sentence fails any test above:
- Rewrite it
- Or remove it

Consistency beats expressiveness.
